    Setiap catatan menyimpan

    Design token

    Nilai dari assets/css/jfresh.css, per perangkat.

    Teks validasi & pesan

    Katakan apa yang salah dan cara memperbaikinya, dengan kata sehari-hari, tepat di bawah field.

    Tulis

    • Berat wajib diisi.
    • Jumlah bag harus lebih dari 0.
    • Pilih alasan.
    • Cucian berhasil diterima. Lanjut ke Sorting.
    • Koneksi terputus. Data akan dikirim saat online kembali.
    • Ada Masalah · Cocokkan Data · Siap Dikirim

    Jangan tulis

    • weight_required_error
    • Invalid value for field qty_bag
    • Field reason is mandatory (ERR-422)
    • Transaction posted to GL successfully
    • HTTP 503 Service Unavailable
    • Create Non-Conformance Report · Reconciliation Journal · Dispatch Order

    Bahasa

    Bahasa Indonesia adalah default. English tersedia dengan satu tap di setiap layar.

    • Setiap label disimpan sebagai pasangan [Indonesia, English] di satu file konfigurasi. Tidak ada teks yang ditulis langsung di layar.
    • Tombol ID | EN ada di top bar dan diingat per perangkat.
    • Kata operasional yang sudah dipakai tim: Terima Cucian, Ada Masalah, Siap Dikirim. Tanpa istilah ERP di layar frontline.
    • Kode (Screen ID, kunci izin, event audit) tetap sama di kedua bahasa.
